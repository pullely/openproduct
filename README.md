# openproduct

[openproduct.live](https://openproduct.live) is a public directory of open
builds: products made in public, with their code, their plan and their work
in progress visible while it happens. Anyone can browse listings, people,
threads and the weekly digest without signing in. Makers list products from
public [Orunbase](https://orunbase.com) workspaces, and contributors save,
follow, endorse, comment and apply for open roles.

## Status

openproduct is being rebuilt here, in the open, as a standalone,
Cloudflare-only product: Workers, D1, R2 and Durable Objects, deployed through
Orunbase like every product it lists. The plan is the
[`openproduct-standalone`](specs/epics/openproduct-standalone/README.md) epic.
The epic and its tasks are tracked in Orunbase; this repository holds the
product's code (cut from its old home at OPN1, and verify-only until OPN2
deploys it), the design and the task contracts. To report a security issue,
see [SECURITY.md](SECURITY.md).

Until that epic's switch milestone, openproduct.live is still served by the
previous deployment.
