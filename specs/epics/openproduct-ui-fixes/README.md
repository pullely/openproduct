Improvements and fixes to the openproduct UI. Each owner request becomes
a milestone: designed on the Claude Design canvas first, then built here.

| Milestone | Task | What lands |
|---|---|---|
| UF1 — one layout on every page | UF-1 | One fluid shell, fixed rails, filters in the left rail, the three tab pages share one layout |
| UF2 — frosted centred navbar | UF-2 | The calm 56px bar in Geist, centred plain-text sections, frost that melts into the page, ivory + amber glow, no dots |
| UF3 — calm tab switching and feed loading | UF-3 | Content-only crossfade, gliding section underline, no progress bar, feed skeleton only while loading |

The epic is done when every milestone the owner asked for is live and the
canvas matches the site.
